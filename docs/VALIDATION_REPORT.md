# Revision AU engineering validation report

## Evidence baseline
Revision AS: 8 ERC errors, 377 warnings, generated by KiCad on macOS. No KiCad executable is available in this working environment; Revision AU ERC has NOT been run.

## Confirmed manufacturer correction
TI TPS630701 datasheet SLVSC58B identifies pin 6 FB2 as **voltage scaling output**, not input; it may be left open when unused. Corrected cached and project-library FB2 pin electrical type from `input` to `output`. Existing no-connect marker retained. This should address the input-not-driven diagnostic, but must be checked by KiCad ERC.

## Unresolved critical findings
- U1 VIN_A: netlist identifies VMOTOR, but no recognized source driver. Verify battery protection path and use a PWR_FLAG only if the physical power-source net is confirmed.
- U4 VCCA: MB_EDGE_3V is an externally powered micro:bit rail; source declaration and USB/battery off-state require bench verification.
- J70 CTRL: Pololu QTRX emitter control is meaningful and may default high; physical module/harness pin map must be verified before deciding whether to leave open or drive. J70 NC similarly needs exact pin validation.
- J2 obsolete interface: DNP/excluded from BOM/PCB; retained until its second pin/net is reviewed.
- D20 GND: GND net exists; missing source-driver error is not grounds for adding a fake supply.
- 377 warnings include off-grid pin/wire geometry, five missing footprint references and isolated labels. No automatic coordinate snapping has been performed because it could alter connectivity.
- **Critical manufacturer issue:** TPS630701 pin 14 is EN, not VIN; the cached symbol labels pin 14 EN, but the netlist must be checked for erroneous VMOTOR wiring. Stop PCB release if pin 14 is tied to supply without appropriate EN design review.
